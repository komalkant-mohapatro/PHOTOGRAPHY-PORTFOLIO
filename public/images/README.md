# Komalkant Mohapatro Photography Folder

Place your original photography files in this directory (`public/images/`).

For example:
- `hero.jpg`
- `portrait-01.jpg`
- `travel-01.jpg`
- `cinematic-01.jpg`
- `street-01.jpg`
- `landscape-01.jpg`

You can reference local images in `src/data/photos.ts` by updating the `image` field:
```ts
image: '/images/hero.jpg'
```
